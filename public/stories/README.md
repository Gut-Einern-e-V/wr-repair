# Bilder für Reparaturgeschichten

Hier liegen die Bilder, die in den Geschichten unter `content/stories/`
erscheinen. Ein Bild hierher legen, den Dateinamen in der Markdown-Datei
eintragen, committen – fertig. Die Anleitung dazu steht in
`content/stories/README.md`, Abschnitt „Bilder“.

**Dateinamen** klein schreiben, mit Bindestrichen, ohne Umlaute und
Leerzeichen. Am besten mit dem Namen der Geschichte beginnen, dann liegen die
Bilder einer Geschichte im Ordner beieinander:

```
naehmaschine-laeuft-wieder.jpg
naehmaschine-laeuft-wieder-detail.jpg
```

**Format** JPEG für Fotos, PNG für Grafiken. WebP und GIF gehen auch.

**Größe** höchstens etwa 1600 Pixel an der langen Kante und unter 500 KB. Die
Seite rechnet die Bilder beim Ausliefern selbst herunter, aber die Datei liegt
für immer im Repository – ein Foto direkt aus der Handykamera bläht es
unnötig auf.

Ein Bild, auf das keine Geschichte mehr zeigt, darf gelöscht werden.
